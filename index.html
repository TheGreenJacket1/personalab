Diagnosis & Troubleshooting

        

        

          HTTP 401: Unauthorized
          
Kunci API tidak valid atau terdapat spasi tak sengaja. Salin ulang kunci dari konsol Groq dan simpan kembali.

        

        

          HTTP 404: model_not_found
          
Model telah didegradasi/pensiun oleh Groq. Aktifkan auto-fallback atau pilih openai/gpt-oss-20b.

        

        

          HTTP 429: Rate Limit Exceeded
          
Batas request per menit tercapai. Sistem menerapkan jeda otomatis 2.5 detik sebelum mencoba kembali.

        

        

          Respon Kosong ('')
          
Karakteristik model keluarga gpt-oss bila max_tokens di bawah 300. Workbench ini menetapkan batas minimal 400 token untuk menjamin kelengkapan teks.

Prinsip Arsitektur LLM & Metodologi Prompting

          
Aplikasi ini dirancang sebagai instrumen laboratorium untuk mendemonstrasikan perilaku dasar Large Language Models (LLM) saat dioperasikan melalui API tanpa perantara backend terpusat (serverless client-side architecture).


          

            
              

                Komponen
                Mekanisme Implementasi
                Rasional Teknis
              

            
            
              

                Stateless Conversation
                Mengirim ulang seluruh riwayat percakapan pada setiap request HTTP.
                API model inferensi tidak menyimpan memori antar panggilan. Tanpa injeksi array messages, model memperlakukan tiap prompt sebagai sesi baru.
              

              

                Sliding Window Memory
                Pemotongan riwayat pada 6 giliran terakhir (12 pesan: 6 user + 6 assistant).
                Mencegah pembengkakan konsumsi kuota token konteks serta menjaga latensi inferensi tetap rendah tanpa menghilangkan konteks langsung.
              

              

                Parameter Decoding
                Temperature 0.2 untuk dosen akademis; 0.4 untuk mentor karier dan kakak santai.
                Nilai temperature rendah menekan variansi token (deterministik), cocok untuk persona formal yang terikat batasan ketat. Temperature sedikit lebih tinggi memberikan keluwesan idiomatis.
              

              

                Instruction Dilution
                Pengujian dengan menyatukan instruksi kontradiktif ke dalam satu system prompt.
                Membuktikan bahwa menambahkan terlalu banyak kriteria bertentangan menyebabkan model melakukan "cherry-picking" dan mengabaikan aturan esensial.
              

            
          


          
Penerapan Standar Anti-Slop

          
Proyek ini mengadopsi prinsip Anti-Slop Engine guna memastikan fungsionalitas dan kejujuran teknis:

          
    
            
  • Tanpa Bukti Palsu (Zero Fabricated Metrics): Metrik seperti latensi inferensi dan jumlah kalimat dihitung secara riil dari payload API aktual, bukan simulasi angka acak.
    • 
            
  • Transparansi Payload: Pengguna dapat memeriksa secara langsung system prompt mentah yang dikirimkan ke model melalui panel inspeksi.
    • 
            
  • Aksesibilitas Semantik: Menggunakan standar HTML5 semantik, penanda ARIA yang tepat untuk aliran pesan live, kontras tinggi yang memenuhi standar WCAG, serta penanganan navigasi keyboard.
    • 
            
  • Penanganan Kegagalan yang Jujur: Memberikan kode status HTTP spesifik (401, 404, 429) beserta panduan mitigasi konkret alih-alih pesan kesalahan yang ambigu.
